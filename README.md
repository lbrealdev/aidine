# aidine

`(AY-deen)`

Personal notes on coding agents, LLMs, MCP, and models. Starts with agents.

The name is iodine with `io` swapped for `ai`. In the verse this comes from, iodine is the purple that tells you the flower has medicine. These pages are meant to stay that close to what actually ran.

Not a wiki of every tool. Not `the-guide`. Not a `0k-*`.
