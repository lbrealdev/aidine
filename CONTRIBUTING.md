# Working on aidine

Issue → branch → pull request. Do not commit on `main`.

1. Open an issue.
2. Branch from up-to-date `main` (`docs/…`, `feat/…`, `fix/…`).
3. PR into `main`. Put `Closes #N` in the body.
4. Merge on GitHub, then delete the branch.

The two bootstrap commits already on `main` stay. Do not rewrite them.
