# Grok

xAI has two agent surfaces. Both install on Linux.

| Surface | Binary | What it is |
|---|---|---|
| [CLI](cli.md) | `grok` | Grok Build. Terminal agent. [x.ai/cli](https://x.ai/cli) |
| [Bot](bot.md) | `grok-bot` | Desktop agent, shipped as a `.deb`. [x.ai/bot](https://x.ai/bot) |
