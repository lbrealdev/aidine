# Harness

A harness here is the layer around an agent you already use: memory, everyday workflow, optional formal phases, review, skills, and guards. It configures and steers; it does not replace the agent binary.

Agent install and day-to-day use stay under [agents/](../agents/README.md). This section covers shared tooling that wraps those agents.

## In this section

- [Gentle-AI](gentle-ai.md) — memory, ODD/SDD, RDD review across many agents
- [Gentle Shell](gentle-shell.md) — Pi-native workspace UI (npm package still `gentle-pi`)
